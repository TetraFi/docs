`GET /api/v1/prices` returns each venue's current price for a pair from prices TetraFi already holds. Use it to show prices, size a trade or choose venues, then [request quotes](/search/how-it-works) to trade.

- No venue is asked, so it is fast and does not use the [quote limit](/reference/rate-limits).
- A price is never firm and can never be ordered: every row carries `firm: false`. Only a quote has an `id` you can order.
- A venue that publishes no price (`priceSourceNone`) answers only a quote request.

You need a key with [**Read quotes**](/authentication#permissions) (`prices_read`) ([Before your first trade](/before-you-trade)).

## Query parameters

| Parameter | Required | Value |
| --- | --- | --- |
| `sell`, `buy` | Yes | Asset ids from [`GET /api/v1/assets`](/search/how-it-works#use-values-from-discovery). |
| `sellAmount`, `buyAmount` or `sizes` | Exactly one | One amount you sell or buy, or `sizes`: 1 to 8 comma-separated sell amounts, such as `100,1000,10000`. |
| `sell.chain`, `buy.chain` | No | A CAIP-2 chain id to pin that side. |
| `locations`, `modalities`, `venues.include`, `venues.exclude`, `variants.sell`, `variants.buy` | No | The [quote filters](/search/filters-and-sort), comma-separated. A venue they exclude has no row. |

## The response

```json Response expandable

  "sell": "USDC",
  "buy": "ETH",
  "computedAt": "2026-10-27T00:33:10.650366067Z",
  "referenceMid": { "sellUsd": "0.99965", "buyUsd": "2323.71", "buyPerSell": "0.00043019" },
  "sellBalances": [],
  "rows": [
    {
      "status": "priced",
      "venue": { "id": "...", "modality": "rfq" },
      "location": { "kind": "offChain" },
      "sellVariant": { "kind": "native", "name": "USDC" },
      "buyVariant": { "kind": "native", "name": "ETH" },
      "firm": false,
      "lastLook": false,
      "basis": "levels",
      "observedAt": "2026-10-27T00:33:09.731Z",
      "staleAfter": "2026-10-27T00:33:14.731Z",
      "sizes": [
        {
          "sell": "100",
          "buy": "0.04302555",
          "netReceived": { "kind": "unavailable", "reason": "comparisonCostsUnavailable" },
          "filled": "full",
          "fees": []
        }
      ],
      "levels": [{ "size": "11621", "price": "0.00043025557" }],
      "spreadFromMidBps": { "kind": "unavailable", "reason": "comparisonCostsUnavailable" }
    },
    {
      "status": "unsupported",
      "reason": "priceSourceNone",
      "venue": { "id": "...", "modality": "amm" },
      "location": { "kind": "singleChain", "chain": "eip155:84532" },
      "sellVariant": { "kind": "native", "name": "USDC" },
      "buyVariant": { "kind": "wrapped", "name": "WETH" },
      "sizes": [],
      "spreadFromMidBps": { "kind": "unavailable", "reason": "noPrice" }
    }
  ]
}
```

There is one row per venue, location and variant pair, sorted like quotes, with rows that hold no price last.

| Field | Meaning |
| --- | --- |
| `sizes[]` | One entry per size you asked for: `sell`, `buy` (after included fees; `null` when nothing could be priced), `netReceived`, `filled` (`full`, `partial` or `none`) and `fees`. |
| `basis` | `levels` (the venue's published levels) or `model`. |
| `observedAt`, `staleAfter` | When the price was seen, and when it is old. |
| `levels` | The venue's own price levels, in sell units, where it publishes them. |
| `spreadFromMidBps` | The spread from the reference mid at the first size, or `unavailable` with a reason, never 0. |
| `referenceMid` | The pair's reference price. `null` when it could not be read, with the reason in `referenceMidUnavailable`. |
| `computedAt` | When this snapshot was built; it is reused for about a second. |
| `sellBalances` | Always empty for an API key. |

| `status` | Meaning |
| --- | --- |
| `priced` | A current price. |
| `stale` | Past `staleAfter`, or the source is warming up. Any price it holds is kept. |
| `unsupported` | `pairNotServed`, `priceSourceNone` (only a quote request asks it) or `buyAmountUnsupported`. |
| `belowMin`, `insufficientDepth` | The first size is below the venue's minimum, or more than it can fill. |
| `needsWallet`, `restricted` | The venue prices only for a wallet, or a permission keeps the price from you. |
| `unavailable` | A read failed, or a fee could not be worked out; `reason` says which. |

Treat a status you do not recognise as "other".

## Caching, streaming and limits

- Each response carries an `ETag`: send it back in `If-None-Match` to get `304 Not Modified` when nothing changed.
- `GET /api/v1/prices/stream` watches up to 25 pairs (`pairs=USDC:ETH,USDC:EURC` instead of `sell` and `buy`) and sends a `snapshot` server-sent event when a pair changes. Each caller may hold 4 streams at once.
- Price reads have their own limit: `429 PRICES_RATE_LIMIT`, or `429 PRICES_STREAM_LIMIT` for a fifth stream, both with `Retry-After`.

## Refusals

| Status and code | Why | What to do |
| --- | --- | --- |
| `400 UNKNOWN_ASSET`, `UNKNOWN_CHAIN`, `UNKNOWN_VENUE` | A value is not in the catalogue. | Use values from `GET /api/v1/assets`. |
| `400 INVALID_AMOUNT` | An amount or a size is not a positive decimal. | Send positive decimals. |
| `400 SAME_ASSET_NEEDS_CHAIN` | `sell` and `buy` are the same asset with no chain pinned. | Add `sell.chain` or `buy.chain`. |
| `400 INVALID_REQUEST` | Both amounts, `sizes` with an amount, no amount at all, or an unknown parameter, such as `pay`, `receive`, `amount` or `side`. | Send `sell`, `buy` and one of `sellAmount`, `buyAmount` or `sizes`. |
| `403 INSUFFICIENT_SCOPE` | The key lacks `prices_read`. | Use a key with **Read quotes**. |
| `429 PRICES_RATE_LIMIT`, `PRICES_STREAM_LIMIT` | Too many price reads, or streams. | Wait `Retry-After` seconds, or close a stream. |
| `503 PRICES_ELIGIBILITY_WARMING` | Your workspace's prices are still loading. | Retry after `Retry-After` (about 1 second). |
