Security is enforced by architecture, not process alone: every workspace runs its own immutable router with no custody key and no upgrade key, settlement is delivery-versus-payment through escrow, and the refund path is permissionless and can never be paused. See [Settlement & Smart Contracts](/core-concepts/settlement-smart-contracts) for the model.
