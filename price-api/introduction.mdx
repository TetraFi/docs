The price feed streams live indicative prices from TetraFi's solvers and LPs over WebSocket. Subscribe to the corridors you care about and receive continuous updates sized by tier - and, for full-depth consumers, snapshot streams covering aggregated book depth across a network's pairs.

## Where It Fits

* You need **live indicative prices** to estimate a trade before requesting a firm quote from the [RFQ API](/rfq-api/introduction)
* You run a **solver or aggregator** that evaluates TetraFi liquidity continuously without spending quote rate limits
* You want a **standing view of depth** across TetraFi's aggregated LP liquidity on the pairs you route

## Quick Reference

|                    |                                                    |
| ------------------ | -------------------------------------------------- |
| **Transport**      | WebSocket                                          |
| **Authentication** | API key or JWT via the `token` query parameter     |
| **Complexity**     | Medium - subscription management + stream decoding |

## The Flow

| Step | Action           | You send                                         | You get back                                      |
| ---- | ---------------- | ------------------------------------------------ | ------------------------------------------------- |
| 1    | Connect          | `wss://api.tetrafi.io/api/v1/ws?token=<key>`      | Connection established                            |
| 2    | Subscribe        | `prices:{srcChain}:{input}:{dstChain}:{output}:{tier}` topics | Confirmation per topic               |
| 3    | Receive updates  | -                                                | Price events for your corridors, best-first       |

Size tiers (`1k`, `10k`, `100k`, `1m`) let you subscribe at the notional you actually trade - a `100k` subscription prices a hundred-thousand-unit clip, not a spot midpoint. Up to 50 concurrent subscriptions per connection.

See the [Reference](/price-api/reference) for pricing modes and expiry behavior.

## Endpoint Map

| Endpoint                                   | Purpose                                                     |
| ------------------------------------------ | ----------------------------------------------------------- |
| `wss://api.tetrafi.io/api/v1/ws`            | The streaming connection - price and order event topics     |
| `GET /api/v1/pairs`                        | Resolve tradable pairs and asset addresses for subscriptions |
