Subscribe once: continuous indicative updates from TetraFi's solvers and LPs over one WebSocket, per corridor and size tier, or per-network snapshots of the aggregated book.

## Where It Fits

* **Pre-trade sizing** - screen against live prices, spend a firm [RFQ](/rfq-api/introduction) quote only once it clears your bar
* **Continuous evaluation** - watch liquidity around the clock with zero draw on quote rate limits
* **A standing depth picture** across your routed pairs

## Quick Reference

|                    |                                                    |
| ------------------ | -------------------------------------------------- |
| **Transport**      | WebSocket                                          |
| **Authentication** | API key or JWT via the `token` query parameter     |
| **Complexity**     | Moderate - subscriptions and stream decoding are yours |

## From Connect to First Price

| Stage | What happens                                       | Result                                            |
| ----- | -------------------------------------------------- | ------------------------------------------------- |
| 1     | Open `wss://api.tetrafi.io/api/v1/ws?token=<key>`   | Connection established                            |
| 2     | Subscribe: `prices:{srcChain}:{input}:{dstChain}:{output}:{tier}` | Confirmation per topic            |
| 3     | Listen                                             | Price events for your corridors, best level first |

Size tiers (`1k`, `10k`, `100k`, `1m`) price the clip you trade, not a spot midpoint. Up to 50 subscriptions per connection. Pricing modes and expiry: [Reference](/price-api/reference).

## Endpoint Map

| Endpoint                                   | Purpose                                                     |
| ------------------------------------------ | ----------------------------------------------------------- |
| `wss://api.tetrafi.io/api/v1/ws`            | The streaming connection - price and order event topics     |
| `GET /api/v1/pairs`                        | Resolve tradable pairs and asset addresses for subscriptions |
