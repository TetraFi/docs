| | |
| --- | --- |
| **Token** | Answers for its key, with `auth` `oauthClientCredentials`, narrowed to its issued scopes. |
| **Live** | Scopes can shrink while a token is valid: call again, never trust its `scope`. |
| **Wallets** | A workspace key also reads its organisation-wallet grants and signing state. |
| **Signing keys** | Sign this call too ([Sign requests](/authentication#sign-requests)). |

<Accordion title="Fields to read">
| Field | What it tells you |
| --- | --- |
| `auth` | `apiKey` for the key itself; `oauthClientCredentials` for a service-account token. |
| `scopes`, `permissions` | Its current authority, read live. |
| `workspaceId` | The workspace for workspace paths. Absent or `null` when the key is bound to no workspace. |
| `organisationWallets` | Venue trading and wallet grants ([Check readiness](/before-you-trade#check-readiness-from-your-backend)). Each grant lists its `rights`, `["trade"]` today; the list can grow. |
| `rateLimits`, `expiresAt` | The key's own request limit and expiry, when set. |
| `apiVersion` | The API version the key is pinned to ([Versioning](/reference/conventions#versioning)). |
| `venueAccounts` | Which venue accounts the key may trade on: `{"kind": "all"}` today. Narrower kinds, per account, are coming; treat a `kind` you do not know as not all. |

It describes a key or token, not a user profile or verification record.
</Accordion>

<Accordion title="Called from a member session">
A signed-in member can call it too. A revoked or expired session, or a suspended account, answers 401 `INVALID_SESSION`. Profiles and verification are not part of this programmatic contract; when the session's profile cannot be read, it answers 503 `PROFILE_UNAVAILABLE`.
</Accordion>

<Accordion title="Refusals">
| Status and code | Why, and what to do |
| --- | --- |
| 403 `MFA_REQUIRED` | A member session has not completed its second factor. Complete it, then retry. |
| 403 `JWT_REQUIRED` | An API key asked for a profile or verification record, which only a signed-in member reads. |
| 503 `API_KEY_ORGANISATION_WALLET_AUTHORITY_UNAVAILABLE` | The key's organisation-wallet grants or signing state could not be read, so the answer was refused rather than shown empty. Retry shortly, with backoff. |
| 503 `SESSION_AUTHORITY_UNAVAILABLE` | The current workspace or session authority could not be read. Retry shortly, with backoff. |
</Accordion>
