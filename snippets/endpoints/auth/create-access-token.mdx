| **Who** | Active service accounts only (the RFC 6749 client-credentials grant). |
| **Send** | `grant_type=client_credentials`, `client_id` (the account's UUID) and `client_secret` (its `tfk_live_…` or `tfk_test_…` key) as form fields, or the id and secret by HTTP Basic. |
| **Lifetime** | At most 900 seconds: renew before `expires_in` runs out. |
| **Carries** | The account's current workspace role, permissions and API scopes. |
| **Signing keys** | Cannot be exchanged (`SIGNED_KEY_NOT_EXCHANGEABLE`): they sign each request instead. |
