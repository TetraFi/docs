| **When** | Before it is sent. A venue trade is sent at once, so in practice only a pay-in waiting for funds. |
| **Too late** | Once claimed for dispatch, its funding moved, or it ended: 409 `ORDER_NOT_CANCELLABLE`, with `details.status`. |
| **Answer** | The order: read its `status` and `terminal`. |
| **Idempotency-Key** | Required for API keys. Cancelling again leaves the order unchanged. |
| **Permission** | Key scope `orders_write`; a member who can place orders. |
| **Venue** | On a `basicTrade` today, nothing is cancelled at the venue, and nothing is refunded ([Cancel an order](/trade/orders#cancel-an-order)). |
