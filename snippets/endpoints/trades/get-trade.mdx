<Accordion title="Views for signed-in members">
`scope` (`mine`, `workspace` or `umbrella`) and `perspective` work as on the list. The umbrella view is a broker's record with the client category's field visibility. `perspective=maker` is an LP's fill with pseudonymised counterparties, for a member of an LP workspace allowed to view settlements; `venueId` names the LP's own venue that filled it, and `flow` is `protocol`, `venueAccount` or `all`. With an API key these views answer 403 `JWT_REQUIRED`.
</Accordion>

<Accordion title="Refusals">
A `404` with no code means no trade with this id in this view.

| Status and code | Why, and what to do |
| --- | --- |
| 400 `INVALID_REQUEST` | A list filter, or a parameter this view cannot apply. `field` names it. |
| 403 `RECORDS_OUT_OF_SCOPE` | Another member's order, and you cannot view the workspace's compliance records. |
| 403 `INSUFFICIENT_SCOPE` | The key lacks `trades_read`. |
| 403 `JWT_REQUIRED` | `scope=mine`, the umbrella or the maker view with an API key. |
| 404 `WORKSPACE_NOT_FOUND` | The path's workspace is not your key's. |
| 503 `TRADE_PROJECTION_UNAVAILABLE` | This view is not available on this deployment. Retry later. |
</Accordion>
