| 404 `WEBHOOK_NOT_FOUND` | Use an id from this workspace's webhook list. |
| 409 `WEBHOOK_EXISTS` | Another endpoint already has that URL. |
| 412 `WEBHOOK_VERSION_CONFLICT` | It changed since you read it; nothing changed. Read it again first. |
| 428 `WEBHOOK_VERSION_REQUIRED` | `If-Match` is missing or a wildcard; nothing changed. |
| 503 `WEBHOOK_AUTOMATION_AMOUNTS_UNAVAILABLE` | Nothing changed. Retry shortly. |
