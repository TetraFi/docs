## Transports

| Interface | What you can use today |
| --- | --- |
| REST | JSON over HTTP under `/api/v1`: discovery, quotes, order placement and order reads. Start with [How search works](/search/how-it-works) and [Place an order](/trade/orders). |
| Server-sent events (SSE) | `POST /api/v1/quotes` accepts `Accept: text/event-stream` for a fresh search; a requote returns JSON, never a stream. `GET /api/v1/prices/stream` streams price snapshots. See [quote streaming](/search/how-it-works#json-or-a-stream) and [price streaming](/search/prices). |
| Webhooks | Receive workspace events, including `order.updated`, then read the order's current state. See [Webhooks](/trade/webhooks) for registration, signatures and redelivery. |
| FIX | Not supported. Use the REST order API, not a FIX session. |

Quote SSE reports the search, not the order's execution. Follow orders through REST status reads or webhook notifications; do not treat the end of a quote stream as an order outcome.

## SDK availability

A TypeScript SDK exists in the source repository, but it is not published to a package registry. There is no public registry install to depend on today. You can integrate directly over HTTP using the [public API reference](/reference/introduction); the protocol does not require the SDK.

## Times and durations

Read each field's schema rather than assuming every time is a string.

| Field or value | Wire format |
| --- | --- |
| Quote `expiresAt`, `observedAt`, `staleAfter`; order `settlesBy` | RFC 3339 date-time strings in UTC, or `null` where the schema allows it. |
| Error-body `timestamp` | Integer Unix **seconds**, not milliseconds or an RFC 3339 string. |
| Continuation repricing offer `expiresAt` | Integer Unix **seconds**. This is not the quote's date-time `expiresAt`. |
| Owner authorization `requestExpiryMs`, when present | Integer Unix **milliseconds**, the provider request expiry. |
| `eta` and `retryAfter` durations | ISO 8601 durations, not timestamps. |

[Conventions](/reference/conventions) covers amounts, ids, pagination, headers and versioning. [Settlement timing](/trade/settlement-timing) explains what an order deadline does and does not promise.
