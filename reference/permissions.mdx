Each API operation below lists the API-key scopes it needs. A key names its scopes when you create it ([Authentication](/authentication#permissions)); each scope is `<resource>_read` or `<resource>_write`.

| Entry | Meaning |
| :--- | :--- |
| Two scopes in one cell | The key needs both. |
| Scopes joined by “or” | Either set is enough. |
| **None** | Any valid key may call it; it still needs authentication. |
| **Session only** | Signed-in app users only; an API key is refused. |
| **No API key required** | Called without an API key; the request carries its own credentials. |

## Scopes

| Scope | Label | What it allows |
| :--- | :--- | :--- |
| `access_requests_read` | Read access requests | Read your own permission requests, those waiting on you and their approvers. |
| `access_requests_write` | Write access requests | Ask for a permission and cancel your own request. Deciding stays with a person. |
| `admin` | Admin | Protocol administration routes. |

| `alerts_read` | Read alerts | Read expiry alerts (alerts with source=expiry). |

| `liquidity_providers_write` | Write liquidity providers | Enable, disable and scope the workspace's liquidity providers. |
| `members_read` | Read members | Read workspace members and member compliance. |
| `orders_read` | Read orders | Read orders and their status. |
| `orders_write` | Write orders | Place orders and run order preflights. |
| `prices_read` | Read prices | Read prices and the asset catalogue. |
| `profiles_read` | Read profiles | Read the workspace's and counterparties' public profiles. |

| `quotes_read` | Read quotes | Read quote requests and the quote stream. |
| `quotes_write` | Write quotes | Request quotes, fresh or as a requote. Needs orders_write on the same key. |

| `settlement_reports_write` | Write settlement reports | Report a bank deposit or payout as an LP with no fiat API. LP workspaces only. |
| `settlements_read` | Read settlements | Read settlement records, obligations, positions and OTC accounts. |
| `settlements_write` | Write settlements | Move OTC account funds and authorize their ledger entries, and the workspace's fiat settlement writes. |
| `solvers_read` | Read solvers | Read LP solver configuration and runtime status. |
| `solvers_write` | Write solvers | Change LP solver configuration. |
| `trades_read` | Read trades | Read trades, their settlement and trade ledger events. |
| `treasury_read` | Read treasury | Read treasury wallets, balances, transfers and approvals. |
| `treasury_write` | Write treasury | Start treasury transfers. Custodian approvals still apply. |
| `users_read` | Read users | Read the broker's users, direct users included. |
| `users_write` | Write users | Onboard direct users into the broker's umbrella. |
| `venue_code_suggestions_write` | Write venue code suggestions | Replace the asset identity importer's venue code suggestions and read the venue code review list. Platform credentials only, held alone, always with an expiry of at most 90 days. Like every key, it can also read its own identity (GET /api/v1/me). |
| `venue_trades_write` | Write venue trades | Quote and trade on the workspace's own venue accounts. Needs a signing key with its venue switch on and a non-empty IP allowlist. |
| `webhooks_write` | Write webhooks | Manage webhook endpoints, test them and read or retry their deliveries. |
