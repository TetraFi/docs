These pages are generated from the API's integrator specification, so they always match what the API accepts and returns. The guides explain how the operations fit together; start with the [Quickstart](/quickstart) if you are new.

<Note>
The API may change until launch. Every change is listed in the [Changelog](/changelog), and the [Compatibility policy](/compatibility) says what can change after launch.
</Note>

## Base URL and authentication

Send every request to `https://api.tetrafi.io` with your API key in `X-API-Key` and your workspace in `X-Workspace-Id`. A key with venue trading also signs each request. [Authentication](/authentication) covers both.

## Reading responses

- Ignore response fields you don't recognise; objects can gain fields.
- Treat an enum value you don't recognise as "other": every response enum in the specification is open.
- Every refusal is one error body. [Errors and refusals](/trade/errors) explains how to read it, and [Error codes](/reference/error-codes) lists every code and source reason.
