---
title: "Batch"
description: "Run up to 20 reads in one request."
---

1. **Batch** up to 20 `GET` reads in one `POST /api/v1/batch`. Each runs with your own permissions and answers on its own, in request order.
2. **Send signed reads separately**: a signed request cannot be batched.

Full explanation: [Read several resources at once](/reference/conventions#read-several-resources-at-once).
