---
title: "Authentication"
description: "Check the credential you call with, or exchange a service account's credentials for a short-lived token."
---

1. **Create** an API key in the app, and send it as `X-API-Key` on every request.
2. **Sign** every request when the key signs. A key with venue trading always does.
3. **Exchange** a service account's id and key for a bearer token with `POST /api/v1/oauth/token`. It lasts at most 900 seconds.
4. **Check** what your key or token can do right now, and its pinned `apiVersion`, with `GET /api/v1/me`, before you trade.

Full explanation: [Authenticate](/authentication).
