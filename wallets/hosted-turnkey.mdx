A Turnkey wallet is a [hosted wallet](/wallets/overview): Turnkey runs the key in a secure enclave, and your owners approve every payment. It shows as "Runs on Turnkey". Turnkey wallets are EVM or Solana.

| Connection | Status |
| --- | --- |
| **Bring your own account**: wallets live in your Turnkey organisation | Available |
| **Provided by TetraFi**: wallets live in TetraFi's Turnkey account | Rolling out |

## Connect your Turnkey organisation

You need **Manage credentials** and your Turnkey organisation ID. TetraFi makes the API key; you never send it a private key.

<Steps>
  <Step title="Start the connection">
    In **Treasury › Providers**, under Turnkey, choose **Connect your Turnkey account**. Enter your Turnkey organisation ID and, if you like, a name for it in TetraFi, such as *Treasury ops*. Choose **Continue** and confirm with your second factor.
  </Step>
  <Step title="Add TetraFi's key in Turnkey">
    TetraFi shows a public key (P-256). In Turnkey, open **Users** and create a user, for example `tetrafi`. Do **not** add it to the root quorum. Add an API key to that user and paste the public key. The key waits for you for 7 days.
  </Step>
  <Step title="Check">
    Back in TetraFi, choose **Check**. The connection reads **Connected**. If you close the dialog with **I'll finish later**, choose **Check connection** in **Treasury › Providers** once the key is added.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="What TetraFi can do with the connection">
    TetraFi can read every wallet in the organisation and its sub-organisations. What it may do with each wallet is set by your Turnkey policies, one wallet at a time. Its user is never a root user, so TetraFi can never act as an owner of your organisation. If the key sits on a root user, TetraFi refuses to create wallets on the connection and says why.
  </Accordion>
  <Accordion title="Replace the key">
    In **Treasury › Providers**, choose **Rotate key** on the connection. TetraFi makes a new key; add it to the same Turnkey user and choose **Check**. TetraFi uses the new key from then on. The old key keeps working at Turnkey until you remove it there, so remove it.
  </Accordion>
</AccordionGroup>
