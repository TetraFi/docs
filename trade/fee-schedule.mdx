title: "Read your fee schedule"
description: "Read the TetraFi fees your workspace pays now, per venue, and the changes already scheduled."
---

`GET /api/v1/workspaces/{workspaceId}/fee-schedule` answers the schedule in force now and every change already scheduled. It reads only.

## You need

- **Read fee schedule** on the key ([Permissions](/authentication#permissions)). Every member can read fees, but a key needs this permission: no other includes it.
- Your workspace id, the `workspaceId` from `GET /api/v1/me`.

## Read the schedule

<FeeScheduleRead />

```json Response (shortened) expandable
{
  "workspaceId": "36ff6481-…",
  "current": {
    "defaultRates": {
      "platform": { "ratePpm": "100", "effectiveFrom": "2026-10-27T00:00:00Z" },
      "grossPlatform": { "ratePpm": "100", "effectiveFrom": "2026-10-27T00:00:00Z" },
      "takerIncentive": null,
      "makerShare": null
    },
    "venues": [],
    "partnerArrangementApplies": false
  },
  "upcoming": []
}
```

<ResponseField name="current" type="object">
  The schedule in force.
  <Expandable title="schedule">
    <ResponseField name="defaultRates" type="object">The rates every venue uses unless it is listed in `venues`.</ResponseField>
    <ResponseField name="venues" type="array">The venues whose rates differ, each with its own `rates`.</ResponseField>
    <ResponseField name="partnerArrangementApplies" type="boolean">`true` when your workspace has a partner arrangement with the venue.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="upcoming" type="array">
  Scheduled changes, oldest first, each with its `effectiveFrom` and the whole `schedule` from then. `[]` means none.
</ResponseField>

| Rate | Meaning |
| --- | --- |
| `platform` | Your charged rate, after any taker incentive. |
| `grossPlatform` | The rate before the taker incentive. |
| `takerIncentive` | The share of the gross fee rebated to you; `null` if none. |
| `makerShare` | The fee share you earn as the venue's partner maker; `null` if none. Never shows another workspace's arrangement. |

Each rate has `ratePpm` and `effectiveFrom`:

- `ratePpm`: a decimal string in parts per million (100 ppm is one basis point, 0.01%). Read it as a decimal, not a float.
- `effectiveFrom`: the RFC 3339 date-time it applies from.

## Refusals

| `error` | Status | What to do |
| --- | --- | --- |
| `INVALID_REQUEST` | 400 | The path's workspace id is not a UUID. |
| `FEE_SCHEDULE_UNAVAILABLE` | 503 | Unreadable; no partial or zero schedule is sent. Retry shortly. |

A key without **Read fee schedule** is refused with `403`. Every other code is in [Error codes](/reference/error-codes).
