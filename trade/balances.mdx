These reads need the **Treasury read** permission and never move money. Every path names your workspace: `TETRAFI_WORKSPACE_ID` is the `workspaceId` that `GET /api/v1/me` answers for your key.

## Every balance in one list

`GET /api/v1/workspaces/{workspaceId}/balances` lists what each wallet and exchange account the key may read holds, one row per account, asset and chain. It reads the last observation TetraFi holds and never asks a chain or venue for a new one. Personal wallets are never listed, and bank account balances cannot be observed.

| Field | Meaning |
| --- | --- |
| `id` | The row's id. Opaque: never parse or build one. |
| `accountKind` | `wallet`, `venueAccount` or `bankAccount`. Show a kind you do not recognise as it is. |
| `accountId` | A wallet's `walletId`, or the exchange account's `venueAccountId`. |
| `asset`, `chain` | The asset and its CAIP-2 chain; `chain` is `null` off-chain, such as at an exchange. |
| `nativeAssetId` | The asset's id at its source, such as a token contract, when known. |
| `amount` | Everything held, as a decimal string in whole asset units. |
| `asOf`, `freshness` | When it was observed, and `fresh`, `stale` or `partial`. Treat an unknown freshness as `stale`. |

Filter with `asset`, `accountKind` and `accountId`; page with `limit` (1 to 100) and `cursor` until `nextCursor` is `null`. When your accounts change while you page, start again without a cursor.

### Balances that are unknown

An account whose balance cannot be stated is listed in `unavailable`, never as a zero row: show it as unavailable, not empty. Each entry has `accountKind`, `accountId`, the `asset` and `chain` when known, a `reasonCode` and the `asOf` of the source's last answer. It is repeated on every page.

`incomplete`, when present, means the list may leave accounts out; `reason` `accessSettingsUnavailable` says the workspace's access settings could not be read. Read again shortly.

<BalancesUnavailable />

```json Response (shortened)
{
  "items": [],
  "nextCursor": null,
  "unavailable": [
    { "accountKind": "venueAccount", "accountId": "169e142e-…", "asset": null, "chain": null, "reasonCode": "…", "asOf": null }
  ],
  "incomplete": { "reason": "accessSettingsUnavailable" }
}
```

## List your exchange accounts

`GET /api/v1/workspaces/{workspaceId}/venue-enablements` lists the workspace's venue accounts, oldest first, in `items`, paged with `limit` (20 by default, at most 100) and `cursor`. Key each item by `venueEnablementId`.

| Field | Meaning |
| --- | --- |
| `accountId` | The `venueAccountId` the reads below take. Absent for a wallet-based venue. |
| `venueKind` | `accountBased` (the venue holds your money in the account) or `walletBased` (it trades from your own wallets: read those). |
| `fundingTarget` | Where the money lives: `{kind: "venueAccount", accountId}` or `{kind: "tradingWallets", walletIds}`. Treat another kind as "other". |
| `venueId`, `label` | The venue, such as `binance` (`null` when unknown), and the account's name in the app. |
| `lifecycle` | `pending`, `configured`, `funding_only`, `disabled` or `revoked`. Read balances from a `configured` account; treat another value as unusable. |
| `tradePaused`, `withdrawalPaused` | Whether trading or withdrawals are paused. |

## One exchange account

`GET …/venue-accounts/{venueAccountId}/balances` answers what the venue last reported for the account:

| Field | Meaning |
| --- | --- |
| `state` | `supported` when the balance could be read; otherwise a `reason` and `reasonCode` say why. |
| `observedAt`, `expiresAt` | When the venue reported it, and when that reading stops being current. |
| `balances` | One line per asset. `null` means no reading; `[]` means the account holds nothing. |
| `balances[].total` | Everything held, including locked amounts. Negative on an account with credit: what it owes. |
| `balances[].free` | What the venue says is free to trade or withdraw. |
| `balances[].available` | `free` less what TetraFi already committed to open trades and withdrawals; `null` when not known. |
| `balances[].usdValue` | The line's US dollar value; `null` without a reference price, never `0`. |

### Deposits

- `GET …/venue-accounts/{venueAccountId}/deposit-instructions` lists the asset and network pairs the account takes deposits on, in `options`. A venue that publishes no networks answers `options: []` and names its assets in `unconfirmedNetworkAssets`: their networks are not verified, so never send real funds on them.
- `GET …/venue-accounts/{venueAccountId}/deposit-history` lists the deposits the venue credited for one `asset` on one network, `chainRef` (CAIP-2), both required, over the last `lookbackDays` (1 to 30, 7 by default). It is one read of the venue's history, returned whole with `since` and `until` and no cursor. `credits: null` means the history could not be read; `[]` is a real empty history. A window with more than 1,000 venue records answers no credits with `reasonCode` `DEPOSIT_HISTORY_WINDOW_TOO_LARGE`: read a shorter one.

<VenueDepositHistory />

```json Output on test networks
{"asset":"USDC","chainRef":"eip155:11155111","state":"supported","reason":"Terminal credits reported by this venue account in the displayed window. Refresh balances separately before requesting a fresh RFQ.","credits":0}
```

An account's credit line, positions and settlement cycle are on [Settlement and credit](/trade/settlement-and-credit).

## Refusals

| `error` | Status | What to do |
| --- | --- | --- |
| `INVALID_BALANCE_LIST_QUERY` | 400 | Use only `cursor`, `limit`, `asset`, `accountKind` (`wallet`, `venueAccount` or `bankAccount`) and `accountId`. |
| `INVALID_LIMIT`, `INVALID_CURSOR` | 400 | Send a valid `limit`, or start again without a cursor. |
| `OBSERVATION_AUTHORITY_REQUIRED`, `VENUE_READ_AUTHORITY_REFUSED` | 403 | The key has no current authority to read the account, or lost it during the read. Restore its **Treasury read** access. |
| `WALLET_ACCESS_CHANGED` | 403 | The key's access changed while the answer was built. Read again. |
| `WORKSPACE_ACCESS_REQUIRED` | 403 | The key's owner is no longer a member. Use a current member's key. |
| `VENUE_ACCOUNT_NOT_FOUND` | 404 | No exchange account with that id in the workspace. |
| `VENUE_ACCOUNT_ELIGIBILITY_CHANGED` | 409 | An account was disconnected while the list was built. Read again. |
| `VENUE_ACCOUNT_REVERIFY_REQUIRED`, `VENUE_ACCOUNT_REVOKED` | 409 | No current venue key reads the account, or it was disconnected. Reconnect it in the app. |
| `VENUE_ACCOUNT_FUNDS_IN_WALLETS` | 409 | The account's money is in your own wallets: read those. |
| `INVENTORY_UNAVAILABLE`, `VENUE_ACCOUNT_ELIGIBILITY_UNAVAILABLE` | 503 | Retry shortly. |

Every other code is in [Error codes](/reference/error-codes).
