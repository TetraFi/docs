Read what each wallet and exchange account holds, in one list or one account at a time. These reads never move money.

## You need

- **Treasury read** on the key ([Permissions](/authentication#permissions)).
- Your workspace id, the `workspaceId` from `GET /api/v1/me`.

## Every balance in one list

`GET /api/v1/workspaces/{workspaceId}/balances` lists what each wallet and exchange account the key may read holds, one row per account, asset and chain. It reads TetraFi's last observation and never asks a chain or venue. Personal wallets are never listed; bank account balances cannot be observed.

| Field | Meaning |
| --- | --- |
| `id` | Opaque: never parse or build one. |
| `accountKind` | `wallet`, `venueAccount` or `bankAccount`; show an unknown kind as it is. |
| `accountId` | A wallet's `walletId`, or the exchange account's `venueAccountId`. |
| `asset`, `chain` | The asset and CAIP-2 chain; `chain` is `null` off-chain, such as at an exchange. |
| `nativeAssetId` | The asset's id at its source, such as a token contract, if known. |
| `amount` | Everything held, a decimal string in whole units. |
| `asOf`, `freshness` | When observed, and `fresh`, `stale` or `partial` (treat an unknown value as `stale`). |

Filter with `asset`, `accountKind` and `accountId`. Page with `limit` (1 to 100) and `cursor` until `nextCursor` is `null`; if accounts change mid-paging, restart without a cursor.

### Balances that are unknown

An account whose balance cannot be stated is listed in `unavailable` on every page, never as a zero row: show it as unavailable, not empty. Each entry has `accountKind`, `accountId`, `asset` and `chain` when known, a `reasonCode`, and the `asOf` of the source's last answer.

`incomplete` means the list may leave accounts out; `reason` `accessSettingsUnavailable` says access settings could not be read. Read again shortly.

<BalancesUnavailable />

```json Response (shortened)
{
  "items": [],
  "nextCursor": null,
  "unavailable": [
    { "accountKind": "venueAccount", "accountId": "169e142e-…", "asset": null, "chain": null, "reasonCode": "…", "asOf": null }
  ],
  "incomplete": { "reason": "accessSettingsUnavailable" }
}
```

## List your exchange accounts

`GET /api/v1/workspaces/{workspaceId}/venue-enablements` lists venue accounts in `items`, oldest first, keyed by `venueEnablementId`. Page with `limit` (20 by default, at most 100) and `cursor`.

| Field | Meaning |
| --- | --- |
| `accountId` | The `venueAccountId` the reads below take. Absent for a wallet-based venue. |
| `venueKind` | `accountBased` (the venue holds your money) or `walletBased` (it trades from your wallets: read those). |
| `fundingTarget` | Where the money lives: `{kind: "venueAccount", accountId}` or `{kind: "tradingWallets", walletIds}`. Treat another kind as "other". |
| `venueId`, `label` | The venue, such as `binance` (`null` if unknown), and the account's app name. |
| `lifecycle` | `pending`, `configured`, `funding_only`, `disabled` or `revoked`. Read balances from `configured`; treat others as unusable. |
| `tradePaused`, `withdrawalPaused` | Whether trading or withdrawals are paused. |

## One exchange account

`GET …/venue-accounts/{venueAccountId}/balances` answers what the venue last reported for the account:

| Field | Meaning |
| --- | --- |
| `state` | `supported` when readable; otherwise `reason` and `reasonCode` say why. |
| `observedAt`, `expiresAt` | When reported, and when the reading stops being current. |
| `balances` | One line per asset. `null` means no reading; `[]` means the account holds nothing. |
| `balances[].total` | Everything held, locked included. Negative on a credit account: what it owes. |
| `balances[].free` | Free to trade or withdraw, per the venue. |
| `balances[].available` | `free` less TetraFi's commitments to open trades and withdrawals; `null` if unknown. |
| `balances[].usdValue` | US dollar value; `null` without a reference price, never `0`. |

### Deposits

| Read | Answers |
| --- | --- |
| `GET …/venue-accounts/{venueAccountId}/deposit-instructions` | The asset and network pairs it takes deposits on, in `options`. |
| `GET …/venue-accounts/{venueAccountId}/deposit-history` | Deposits the venue credited for one `asset` on one `chainRef` (CAIP-2), both required, over the last `lookbackDays` (1 to 30, 7 by default). Returned whole, with `since` and `until` and no cursor. |

<Warning>
A venue that publishes no networks answers `options: []` and lists its assets in `unconfirmedNetworkAssets`. Their networks are not verified: never send real funds on them.
</Warning>

In the history, `credits: null` means it could not be read; `[]` is truly empty. Over 1,000 venue records answers no credits with `reasonCode` `DEPOSIT_HISTORY_WINDOW_TOO_LARGE`: read a shorter window.

<VenueDepositHistory />

```json Output on test networks
{"asset":"USDC","chainRef":"eip155:11155111","state":"supported","reason":"Terminal credits reported by this venue account in the displayed window. Refresh balances separately before requesting a fresh RFQ.","credits":0}
```

## Refusals

| `error` | Status | What to do |
| --- | --- | --- |
| `INVALID_BALANCE_LIST_QUERY` | 400 | Use only `cursor`, `limit`, `asset`, `accountKind` (`wallet`, `venueAccount` or `bankAccount`) and `accountId`. |
| `INVALID_LIMIT`, `INVALID_CURSOR` | 400 | Send a valid `limit`, or start again without a cursor. |
| `OBSERVATION_AUTHORITY_REQUIRED`, `VENUE_READ_AUTHORITY_REFUSED` | 403 | The key has no current authority to read the account, or lost it mid-read. Restore its **Treasury read** access. |
| `WALLET_ACCESS_CHANGED` | 403 | The key's access changed mid-read. Read again. |
| `WORKSPACE_ACCESS_REQUIRED` | 403 | The key's owner left the workspace. Use a current member's key. |
| `VENUE_ACCOUNT_NOT_FOUND` | 404 | No exchange account with that id in the workspace. |
| `VENUE_ACCOUNT_ELIGIBILITY_CHANGED` | 409 | An account was disconnected mid-read. Read again. |
| `VENUE_ACCOUNT_REVERIFY_REQUIRED`, `VENUE_ACCOUNT_REVOKED` | 409 | No current venue key reads the account, or it was disconnected. Reconnect it in the app. |
| `VENUE_ACCOUNT_FUNDS_IN_WALLETS` | 409 | The money is in your own wallets: read those. |
| `INVENTORY_UNAVAILABLE`, `VENUE_ACCOUNT_ELIGIBILITY_UNAVAILABLE` | 503 | Retry shortly. |

Every other code is in [Error codes](/reference/error-codes).
