The API needs no SDK: it is plain HTTPS and JSON. Until the TypeScript SDK is published, build on the samples below. Each one runs as it is; the page snippets are cut from these same files.

## At a glance

| Language | What runs |
| --- | --- |
| cURL (Bash) | Every guide's calls, and each recipe end to end |
| Node.js 18+ | Quickstart, request signing, webhook verification |
| Python 3.8+ | Quickstart, request signing, webhook verification |
| Postman | Every operation ([Postman collection](/reference/introduction#postman-collection)) |
| TypeScript SDK | Not published yet |

The Node.js and Python samples use only the standard library: no packages to install.

<Accordion title="How the samples behave">
  Each API script reads its settings from environment variables (`TETRAFI_BASE_URL`, `TETRAFI_API_KEY`, `TETRAFI_SIGNING_SECRET`, and its own options listed at its top), signs requests when the key has request signing on, and prints one JSON summary as its last line; the webhook verifiers also run offline against a built-in test vector. A script that can place an order stops before ordering unless you set `TETRAFI_PLACE_ORDER=1`, and saves the order record it needs to [recover the order](/trade/orders#retries-and-recovery) before it sends.
</Accordion>
