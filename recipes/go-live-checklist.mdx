## Orders survive a crash

<AccordionGroup>
  <Accordion title="Store the idempotency key before you send">
    Persist `{quoteId, idempotencyKey, exactBody}`, then send `POST /api/v1/orders`; a retry sends the same key and body bytes ([Retries and recovery](/trade/retries-and-recovery)).
  </Accordion>
  <Accordion title="Recover, never reorder">
    A timeout, `5xx` or `outcomeUnknown` does not mean the order failed: replay with the same key, or find the order by its quote.

    <OrderRecoverByQuote />
  </Accordion>
  <Accordion title="Order again only on a new quote">
    Order again only on a new quote, and only when the order is shown not to exist or ended without filling.
  </Accordion>
  <Accordion title="Follow every order to the end">
    Read its `statusUrl` until `terminal` is `true`, every 10 to 15 seconds or when a webhook arrives ([Order status](/trade/order-status)).
  </Accordion>
</AccordionGroup>

## Webhooks are handled once

<AccordionGroup>
  <Accordion title="Verify the signature">
    Verify the signature over the raw body before parsing it.
  </Accordion>
  <Accordion title="Deduplicate on webhook-id">
    Deduplicate on `webhook-id`: deliveries arrive at least once and out of order.
  </Accordion>
  <Accordion title="Answer 2xx within 10 seconds">
    Answer `2xx` within 10 seconds, then work. Read `statusUrl` for the current state.
  </Accordion>
  <Accordion title="Watch for a paused endpoint">
    Resume a paused endpoint and redeliver what it missed. The delivery log does not survive a TetraFi restart ([Webhooks](/trade/webhooks#retries-pauses-and-missed-events)).
  </Accordion>
</AccordionGroup>

## Signing holds up

<AccordionGroup>
  <Accordion title="Sync your clock with NTP">
    `X-Timestamp` must be within 300 seconds of TetraFi's clock, and a write's at most 10 seconds ahead.
  </Accordion>
  <Accordion title="Use fresh nonces">
    Generate every `X-Nonce` from a cryptographic random source, and sign each send, retries included, with a new nonce and timestamp ([Sign requests](/authentication#sign-requests)).
  </Accordion>
  <Accordion title="Keep secrets in a secret manager">
    Keep secrets in a secret manager, never in code or a tracked file.
  </Accordion>
</AccordionGroup>

## Keys can be rotated

<AccordionGroup>
  <Accordion title="Pick up a rotated key within one hour">
    After **Rotate key**, the old key works for one hour ([Rotate and revoke](/authentication#rotate-and-revoke)).
  </Accordion>
  <Accordion title="Grant only the permissions a key uses">
    Grant only the permissions a key uses.
  </Accordion>
  <Accordion title="Use a service account for software">
    Use a [service account](/service-accounts) for software that should outlive one person's access.
  </Accordion>
  <Accordion title="Know how to revoke a leaked key">
    Know how to revoke a leaked key at once.
  </Accordion>
</AccordionGroup>

## Limits are respected

<AccordionGroup>
  <Accordion title="Watch markets with prices, never by polling quotes">
    Each key may send one live quote request every 3 seconds ([Rate limits](/reference/rate-limits)).

    <SearchPrices />
  </Accordion>
  <Accordion title="On any 429, wait Retry-After and retry once">
    On any `429`, wait `Retry-After` seconds and retry once.
  </Accordion>
  <Accordion title="Requote a held quote">
    Requote a held quote instead of searching again ([Requotes and expiry](/trade/requotes-and-expiry)).
  </Accordion>
</AccordionGroup>

## Parsing tolerates change

<AccordionGroup>
  <Accordion title="Ignore response fields you do not recognise">
    Ignore response fields you do not recognise.
  </Accordion>
  <Accordion title="Treat an unknown enum value as other">
    Treat an unknown enum value as "other", such as a status, source reason or `next.kind`: keep following `terminal`, show `detail` or `message`, and carry on.
  </Accordion>
  <Accordion title="Match refusals on error, never message">
    Match refusals on `error`, never `message`, and treat an unknown code by its status class ([Errors and refusals](/trade/errors#codes-you-do-not-know)).
  </Accordion>
  <Accordion title="Parse amounts as decimals">
    Parse amounts as decimals, never floats ([Conventions](/reference/conventions)).
  </Accordion>
  <Accordion title="Read the Changelog before each release">
    Read the [Changelog](/changelog) before each release of your integration.
  </Accordion>
</AccordionGroup>
