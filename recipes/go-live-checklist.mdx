Before real assets move, check each item below; each links the page that explains it. Then place your first production order at the [smallest amount a venue takes](/quickstart#find-the-smallest-amount-a-venue-takes).

| Check | Link |
| --- | --- |
| Point at the production base URL, with the key you will trade with | [Requests](/reference/conventions#requests) |
| The key has venue trading and signs requests | [Venue trading](/authentication#trade-on-your-venue-accounts) |
| Store `{quoteId, idempotencyKey, exactBody}` before you send | [Retries](/trade/orders#retries-and-recovery) |
| Recover, never reorder: order again only on `notOrdered` or an unfilled end | [Recovery](/trade/orders#the-recovery-sequence) |
| Send `minReceive` when `minReceiveRequired` is `true` | [Minimum receive](/trade/orders#minimum-receive) |
| Handle `SETTLEMENT_WINDOW_CHANGED` on a credit trade | [Settlement window](/trade/settlement-and-credit#order-with-its-settlement-window) |
| Follow every order until `terminal`, every 10 to 15 seconds or on a webhook | [Order status](/trade/order-status) |
| Verify, store, then answer `2xx` within 10 seconds | [Webhooks](/trade/webhooks) |
| Deduplicate webhooks on the body's `id` | [Webhooks](/trade/webhooks) |
| Send a test delivery | [Set up an endpoint](/trade/webhooks#set-up-an-endpoint) |
| Watch for a paused endpoint | [Pauses](/trade/webhooks#retries-pauses-and-missed-events) |
| Sync your clock with NTP; use a fresh nonce on every write | [Sign requests](/authentication#sign-requests) |
| Watch markets with prices, never by polling quotes | [Prices](/search/prices) |
| On a `429`, wait `Retry-After` and retry once, unless the code says otherwise | [Rate limits](/reference/rate-limits) |
| Requote a held quote instead of searching again | [Requote](/search/firmness-and-lifetime#requote-a-quote) |
| Tolerate fields and values you do not know | [Unknown codes](/trade/errors#codes-you-do-not-know) |
| Never sign an unknown step `type` | [What comes next](/trade/sign-with-your-own-wallet#what-comes-next) |
| Match refusals on `error`, never `message` | [Errors](/trade/errors#codes-you-do-not-know) |
| Parse amounts as decimals, never floats | [Conventions](/reference/conventions) |
| Read the changelog before each release | [Changelog](/changelog) |

<Accordion title="Why each check">
| Check | Why |
| --- | --- |
| Base URL | Use the key you will trade with. |
| Venue trading | Without it, nothing on your venue accounts can be ordered (`venueTradeScopeRequired`). |
| Store before you send | A retry sends the same key and body bytes. |
| Recover, never reorder | A timeout, `5xx` or `outcomeUnknown` is not a failure. |
| `SETTLEMENT_WINDOW_CHANGED` | A credit trade's window can move before the order. |
| Answer within 10 seconds | Verify the signature over the raw body before parsing; work afterwards. |
| Deduplicate | Delivery is at least once and out of order; a redelivery gets a new `webhook-id`. |
| Test delivery | `POST …/deliveries` with `{"kind":"test"}`. |
| Paused endpoint | Resume, redeliver, then reconcile orders: receipts kept are capped by `deliveryRetention`. |
| Clock and nonces | `X-Timestamp` within 300 seconds; each write, retries included, gets a new random `X-Nonce` and signature. A read has no nonce. |
| Prices, not quotes | One live quote request per key every 3 seconds. |
| `429` | `PRICES_STREAM_LIMIT` needs a stream closed first. |
| Unknown values | Ignore unknown fields. Treat a value you do not know as other ([Conventions](/reference/conventions#values)); show `detail` or `message`, and keep following `terminal`. |
| Unknown step `type` | `signing.mode`, step `type` and `next.kind` gain values; keep reading until `terminal` is `true`. |
| Unknown codes | Treat an unknown code by its status class. |
</Accordion>

<Accordion title="Keys and secrets">
| Check | Why |
| --- | --- |
| Keep secrets in a secret manager | Never in code or a tracked file. |
| [Pick up a rotated key within one hour](/authentication#rotate-and-revoke) | After **Rotate key**, the old key works for one hour. |
| [Grant only the permissions a key uses; know how to revoke a leaked key at once](/authentication#rotate-and-revoke) | A leaked key does less, for less time. |
| [Use a service account for software](/authentication#service-account-tokens) | It outlives one person's access. |
</Accordion>
