Trade History gives you read-only access to every trade that ran through your workspace. List and filter trades, drill into an individual trade's timeline and settlement evidence, and export the lot - one API surface covering every supported chain.

## Where It Fits

* You need **post-trade analytics** - reconciling fills, tracking volumes, or auditing flow attributed to your workspace
* You want **one query surface for all chains** - no per-network indexing or explorer-hopping to reconstruct what happened

## Quick Reference

|                    |                                                       |
| ------------------ | ----------------------------------------------------- |
| **Transport**      | REST                                                  |
| **Authentication** | API key (results scoped to your workspace)            |
| **Base URL**       | `https://api.tetrafi.io/api/v1/workspaces/{id}/`       |
| **Complexity**     | Low - standard REST GET requests                      |

## The Flow

| Step | Action                | You send                                            | You get back                                        |
| ---- | --------------------- | --------------------------------------------------- | --------------------------------------------------- |
| 1    | List trades           | Filters → `GET /workspaces/{id}/trades`             | Paginated trades with token + settlement detail     |
| 2    | Drill into one        | Trade ID → `GET /workspaces/{id}/trades/{tradeId}`  | Full breakdown: legs, amounts, status, timeline     |

Results are scoped by your credential automatically - [authenticate with your API key](/core-concepts/authentication) and you see exactly your workspace's flow.

## Endpoint Map

| Endpoint                                        | Purpose                                                 |
| ----------------------------------------------- | ------------------------------------------------------- |
| `GET /api/v1/workspaces/{id}/trades`            | List and filter trades with time range and pagination   |
| `GET /api/v1/workspaces/{id}/trades/{tradeId}`  | A single trade's full detail and settlement timeline    |
| `GET /api/v1/workspaces/{id}/trades/export`     | Bulk export for reconciliation and reporting            |
