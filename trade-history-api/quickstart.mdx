This guide covers the two core Trade History surfaces: listing your workspace's trades with filters, and drilling into one trade's full detail.

<Info>
  **What you'll build:** Scripts that fetch and display your workspace's trade history.

  **Time required:** 5 minutes

  **Prerequisites:** An API key for your workspace - results are scoped to it automatically. See [Authentication](/core-concepts/authentication).
</Info>

## 1. List your workspace's trades

Fetch trades across every supported chain in one call - no per-network queries.

```
GET /api/v1/workspaces/{id}/trades
```

| Parameter | Required | Type    | Description                                          |
| --------- | -------- | ------- | ---------------------------------------------------- |
| `id`      | Yes      | string  | Your workspace ID (path parameter)                   |
| `from`    | No       | string  | Start of time range (ISO-8601)                       |
| `to`      | No       | string  | End of time range (ISO-8601)                         |
| `limit`   | No       | integer | Maximum trades per page                              |
| `cursor`  | No       | string  | Continuation cursor from the previous page           |

<CodeGroup>
  ```bash bash theme={null}
  curl "https://api.tetrafi.io/api/v1/workspaces/ws_123/trades?limit=5&from=2026-06-20T00:00:00Z" \
    -H "X-API-Key: tfk_live_..."
  ```

  ```python python theme={null}
  import httpx

  WS = "ws_123"
  headers = {"X-API-Key": "tfk_live_..."}

  resp = httpx.get(
      f"https://api.tetrafi.io/api/v1/workspaces/{WS}/trades",
      params={"limit": 5, "from": "2026-06-20T00:00:00Z"},
      headers=headers,
  )
  data = resp.json()

  for trade in data.get("trades", []):
      legs = trade.get("preview", {})
      inp = legs.get("inputs", [{}])[0]
      out = legs.get("outputs", [{}])[0]
      print(
          f'{inp.get("symbol", "?")} -> {out.get("symbol", "?")}  '
          f'${trade.get("volumeUsd", 0):.2f}  ({trade.get("settledAt", "")})'
      )
  ```
</CodeGroup>

```json theme={null}
      "orderId": "ord_01J49...",
      "status": "settled",
      "product": "rfq",
      "shape": "one-to-one",

        "inputs":  [{ "asset": "eip155:10/erc20:0x0b2C...Ff85",  "amount": "25000000", "symbol": "USDC", "amountUsd": 25.00 }],
        "outputs": [{ "asset": "eip155:8453/erc20:0x8335...2913", "amount": "24987500", "symbol": "USDC", "amountUsd": 24.99 }]

    "results": 1
  }

```

| Field                     | Type            | Description                                                              |
| ------------------------- | --------------- | ------------------------------------------------------------------------ |
| `trades`                  | array           | Trade records, newest first                                              |
| `trades[].tradeId`        | string          | Identifier for detail and timeline lookups                               |
| `trades[].orderId`        | string          | The order this trade settled under                                       |
| `trades[].status`         | string          | Lifecycle state - `settled`, `failed`, in-flight states                  |
| `trades[].product`        | string          | The customer contract the trade ran under: `router` or `rfq`             |
| `trades[].shape`          | string          | Trade shape (see [trade types](#trade-types) below)                      |
| `trades[].corridor`       | string          | Directional route the trade executed on                                  |
| `trades[].solverId`       | string          | The solver or LP that filled it                                          |
| `trades[].preview`        | object          | Inputs and outputs with amounts, symbols, and USD values                 |
| `trades[].volumeUsd`      | number          | Trade volume in USD                                                      |
| `trades[].platformFeeBps` | integer         | Fee applied to this trade, in basis points                               |
| `trades[].txHash`         | string          | Settlement transaction hash                                              |
| `trades[].settledAt`      | string          | Settlement time (ISO-8601)                                               |
| `nextCursor`              | string or null  | Continuation cursor - `null` when you've reached the end                 |
| `metadata.results`        | integer         | Number of records in this page                                           |

### Trade types

| Shape           | Description                                                        |
| --------------- | ------------------------------------------------------------------ |
| `one-to-one`    | Single swap - one input, one output                                |
| `one-to-many`   | One input fanned into multiple outputs                             |
| `many-to-one`   | Multiple inputs consolidated into one output                       |
| `split-fill`    | One intent filled by multiple LPs, each committing a slice        |
| `partial`       | A `partialFill` order that settled below full size, remainder refunded |

### Filtering by time range

Narrow results to a window with `from` and `to`:

<Warning>
  Timestamps are **ISO-8601 strings** (e.g. `2026-06-20T00:00:00Z`), not epoch integers. An epoch value is rejected with a validation error rather than silently returning nothing.
</Warning>

```python theme={null}
from datetime import datetime, timedelta, timezone

import httpx

now = datetime.now(timezone.utc)
month_ago = now - timedelta(days=30)

resp = httpx.get(
    f"https://api.tetrafi.io/api/v1/workspaces/{WS}/trades",
    params={"from": month_ago.isoformat(), "to": now.isoformat(), "limit": 100},
    headers=headers,
)
print(f'Fetched {len(resp.json().get("trades", []))} trades in last 30 days')
```

### Pagination

While `nextCursor` is non-null, pass it back to fetch the next page:

```python theme={null}
import httpx

all_trades = []
cursor = None

while True:
    params = {"limit": 100}
    if cursor:
        params["cursor"] = cursor
    resp = httpx.get(
        f"https://api.tetrafi.io/api/v1/workspaces/{WS}/trades",
        params=params,
        headers=headers,
    )
    data = resp.json()
    all_trades.extend(data.get("trades", []))

    cursor = data.get("nextCursor")
    if cursor is None:
        break

print(f"Fetched {len(all_trades)} trades")
```

## 2. Drill into a single trade

Fetch one trade's full record - legs, status transitions, and settlement evidence:

```
GET /api/v1/workspaces/{id}/trades/{tradeId}
```

| Parameter | Required | Type   | Description                              |
| --------- | -------- | ------ | ---------------------------------------- |
| `tradeId` | Yes      | string | The `tradeId` from the trades list       |

<CodeGroup>
  ```bash bash theme={null}
  curl "https://api.tetrafi.io/api/v1/workspaces/ws_123/trades/tr_01J4A..." \
    -H "X-API-Key: tfk_live_..."
  ```

  ```python python theme={null}
  import httpx

  trade_id = "tr_01J4A..."
  resp = httpx.get(
      f"https://api.tetrafi.io/api/v1/workspaces/{WS}/trades/{trade_id}",
      headers=headers,
  )
  trade = resp.json()

  inp = trade["preview"]["inputs"][0]
  out = trade["preview"]["outputs"][0]
  print(f'{trade["corridor"]}: {inp["symbol"]} -> {out["symbol"]}')
  print(f'Volume: ${trade.get("volumeUsd", 0):.2f}  Product: {trade.get("product")}')
  ```
</CodeGroup>

The detail record extends the list schema with the trade's timeline (status transitions with timestamps) and settlement evidence references.

### Errors

| Code | Detail                                   | Reason                                        |
| ---- | ---------------------------------------- | --------------------------------------------- |
| 401  | `AUTH_REQUIRED`                          | Missing or invalid API key                    |
| 404  | `Trade not found`                        | No such trade in this workspace               |
| 422  | Validation error                         | Malformed timestamp, cursor, or trade ID      |
