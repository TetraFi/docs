---
title: "Speed-Optimised Quotes"
description: "Bias the quote sweep toward latency - fastest answers first for time-critical flows."
mode: "wide"
---

Set `intent.preference: "Speed"` and the sweep is tuned for response time over marginal price improvement: the fastest-answering LPs are prioritised, timeouts tighten, and ranking favors quotes that arrive early. Auction-driven and liquidation-style integrations use this to get an executable answer in as little as ~100 ms from the nearest region.

Latency-critical setups can go further - a dedicated low-latency quoting lane backed by the fastest subset of LPs is available with enablement from the TetraFi team. [Contact support](/support) for access and configuration options (regional endpoints, solver shortlists via `solverOptions`, and tightened sweep timeouts).
