## Networks

Every network is an EVM chain, named by its CAIP-2 id, `eip155:<chain ID>`.

| Chain | CAIP-2 | Status |
| --- | --- | --- |
| Optimism | `eip155:10` | Live |
| Base | `eip155:8453` | Live |
| Ethereum | `eip155:1` | Planned |
| Arc | `eip155:5042` | Planned |

## Flows

Secondary trading, primary issuance, redemption and cross-chain corridors run on the rails; netted settlement and funded fills are coming soon.

<Accordion title="Each flow and its rail">
| Flow | What it is, and its rail |
| --- | --- |
| Secondary trading | Buying or selling an issued token at size. Rail: firm quotes. |
| Primary issuance | Cash into a minted token. Rail: issuer mint capability, as a route leg. |
| Redemption | Token back to cash or stables. Rail: the issuer redemption rail; [Instant Redemption](/collateral/instant-redemption) fronts the wait. |
| Cross-chain corridor | An asset moved between networks. Rail: one quote, one order. |
| Netted settlement (coming soon) | Opposing obligations clear by atomic multilateral set-off; only the residual moves. Rail: [Multilateral Netting](/netting). |
| Funded fill (coming soon) | Destination-chain capital drawn into a fill, repaid by the settlement. Rail: [Solver Credit](/collateral/solver-credit), [Instant Settlement](/collateral/instant-settlement). |

</Accordion>
