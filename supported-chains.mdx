## Asset classes

| Class | What trades |
| --- | --- |
| Regulated stablecoins | USD, EUR and regional-currency stablecoins, at firm LP size |
| Tokenized real-world assets | Treasuries, money-market funds, private credit, commodities, strategies |
| Other tokens | Any other ERC-20 a venue will quote |

<AccordionGroup>
  <Accordion title="Regulated stablecoins">
    Where the depth is greatest: firm LP inventory quotes these at sizes that would move an on-chain pool.

| Group                | Assets                                                     |
| -------------------- | ---------------------------------------------------------- |
| USD                  | USDC, USDT, PYUSD, RLUSD, USDG, AUSD, USDS                 |
| EUR                  | EURC, EURCV                                                |
| Regional currencies  | BRL, MXN, JPY, KRW, CAD, AUD, ZAR, PHP                     |

    Issuer mint and burn rails, such as CCTP and USDT0, compose as legs, so a corridor can cross issuers as well as chains.
  </Accordion>

  <Accordion title="Tokenized real-world assets">
    Tokenized treasuries and money-market funds, private credit, commodities and tokenized strategies are quoted the same way. The issuer's primary rails join the same route: subscription, redemption, secondary trading.
  </Accordion>

  <Accordion title="Other tokens">
    Any other ERC-20 trades wherever a venue will quote it, all through [one quote request](/search/how-it-works):

    - LPs and solvers quote their own corridors.
    - DEX, bridge and fiat sources reach the wider universe.
  </Accordion>
</AccordionGroup>

## Flows

Secondary trading, primary issuance, redemption and cross-chain corridors run on the rails; netted settlement and funded fills are coming soon.

<Accordion title="Each flow and its rail">
| Flow                    | What it is                                                    | The rail                                            |
| ----------------------- | ------------------------------------------------------------- | --------------------------------------------------- |
| Secondary trading       | Buying or selling an issued token at size                     | Firm quotes, escrow-settled                         |
| Primary issuance        | Cash into a minted token                                      | Issuer mint capability, as a route leg              |
| Redemption              | Token back to cash or stables                                 | Issuer redemption rail; [Instant Redemption](/collateral/instant-redemption) fronts the wait |
| Cross-chain corridor    | An asset moved between networks                               | One intent, one signature, escrowed settlement      |
| Netted settlement (coming soon) | Opposing obligations clear by atomic multilateral set-off; only the residual moves | [Multilateral Netting](/netting) |
| Funded fill (coming soon) | Destination-chain capital drawn into a fill, repaid by the settlement | [Solver Credit](/collateral/solver-credit), [Instant Settlement](/collateral/instant-settlement) |

</Accordion>
