Only an order moves assets, so check everything up to the order first, then place the smallest order a venue takes.

<View title="In the app" icon="browser">

The app has no sandbox mode. Each venue account names its site: **Sandbox**, **Testnet** or **Production**. A sandbox or testnet account reads, for example, **Sandbox - test funds**, and its quotes in **Trade** carry the same **Sandbox** or **Testnet** label; on **Production** an order trades real assets.

</View>

<View title="With the API" icon="code">

The API has one environment, production at `https://api.tetrafi.io`, with real assets and venue accounts. Only an order moves assets, so you can build and check everything up to the order: keys, assets, quotes, error handling and webhook signatures (with a test delivery). A fill, its settlement and order events need a real order: make it the smallest one a venue takes.

## At a glance

| Check | Moves assets? |

<Steps>
  <Step title="Check your signer offline">
    Reproduce the published test values with your own request signer before you call the API ([Sign requests](/authentication#sign-requests)).
  </Step>
  <Step title="Quote as much as you like, within the rate limit">
    Quotes cost nothing: one live [`POST /api/v1/quotes`](/api-reference/quotes/request-quotes) every 3 seconds per key ([Rate limits](/reference/rate-limits)). Read every venue's outcome in `sources`.
  </Step>
  <Step title="Test your webhook endpoint">
    [`POST …/webhooks/{webhookId}/deliveries`](/api-reference/webhooks/send-test-delivery) with `{"kind":"test"}` and a new `Idempotency-Key`. The delivery reads `success: true` with your status code once your receiver acknowledged it ([Webhooks](/trade/webhooks#set-up-an-endpoint)).
  </Step>
  <Step title="Place one small order">
    Order the [smallest amount a venue takes](/quickstart#find-the-smallest-amount-a-venue-takes), follow it until `terminal` is `true`, and check every item of the [go-live checklist](/recipes/go-live-checklist).
  </Step>
</Steps>

<Note>
  The samples stop before ordering unless you set `TETRAFI_PLACE_ORDER=1` ([SDK and samples](/sdk)).
</Note>
